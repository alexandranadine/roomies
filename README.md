# Roomies

Shared-household management for roommates.

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- ESLint
- Prettier

## Local development

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

Other useful scripts:

```bash
npm run build        # type-check and production build
npm run type-check   # TypeScript only
npm run lint         # ESLint
npm run format       # Prettier write
npm run format:check # Prettier check
```

## Status

This project is in early development. The current codebase is a frontend foundation only — product features have not been implemented yet.
